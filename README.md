# FOUNDONE - University Inquiry & Lost Property System

This is the frontend implementation for the ICT 1209: Web Technologies mini project. This platform is designed for Rajarata University of Sri Lanka to help students and staff report lost items and claim found properties inside the campus community.

## Project Status
* Phase 2: Frontend Layout & Design

## Technologies Used
* HTML5 & CSS3
* Bootstrap 5 (For styling and responsiveness)
* JavaScript (Vanilla JS for client-side logic)
* Git & GitHub

## Pages Created
1. index.html - Home page with search bar and list of latest lost and found items.
2. report.html - Reporting form for lost and found items.
3. dashboard.html - Dashboard to view and manage reports.
4. auth.html - User login and registration page.

## Key Deliverables in Phase 2
* Fully responsive layout working on mobile and desktop screens.
* Common navigation bar and footer implemented across all 4 pages using external style.css.
* Structured HTML with cards and dynamic mock data for item listings.
